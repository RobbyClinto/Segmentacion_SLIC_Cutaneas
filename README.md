# Demo de diagnóstico de lesiones cutáneas con SLIC

Aplicación Streamlit para demostrar un pipeline de segmentación por superpíxeles SLIC y clasificación con modelos CNN.

## Estructura

- `app.py`: aplicación principal de Streamlit
- `requirements.txt`: dependencias
- `runtime.txt`: versión de Python recomendada para Streamlit Cloud
- `models/`: modelos `.h5`

## Ejecutar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
```
